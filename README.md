# Road Cycling Trainer

An early concept for a road cycling training app. There is no runnable version at this time.

## Features

- Ride planning and route overview
- Training session tracking
- Performance summaries
- Simple, cyclist-focused interface

## Getting Started

This is an early concept only. There is currently no way to run it.

## Usage

- Open the app.
- Create or load a training plan.
- Start a ride session.
- Review metrics and progress after each ride.
